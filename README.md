# Madhu Thakur — Full Stack Developer Portfolio

A professional personal portfolio built with a **React + Vite** frontend and a small, intentional
**Node.js + Express + MySQL** backend.

## Project Structure

```
frontend/    React + Vite (JavaScript) — UI, pages, components, services
backend/     Node.js + Express + MySQL — REST API, auth, validation
```

## Status

This project is being built **phase by phase**. The full README (overview, features, architecture,
API endpoints, database schema, environment variables, install/run steps) will be finalized in the
final phase.

## Workflow

- Frontend: `cd frontend && npm run dev`
- Backend: `cd backend && npm run dev` (added in the backend phase)
